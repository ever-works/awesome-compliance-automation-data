# About Awesome Compliance Automation

Awesome Compliance Automation is a curated, continuously updated directory of software that automates security and privacy compliance — continuous control monitoring, evidence collection, policy management, vendor risk and audit readiness.

## What you'll find here

- **Frameworks** — tools organized by the standards they cover: SOC 2, ISO 27001, HIPAA, GDPR and privacy regulations.
- **Platforms for every stage** — from startups preparing for a first audit to enterprises managing many frameworks at once.
- **Tags** — filter by framework, company size and use case.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new vendors, keep existing listings current and organize everything into categories and tags; every listing links back to the vendor's own site.

Know a compliance tool that should be listed? Use the **Submit** page to add it.
